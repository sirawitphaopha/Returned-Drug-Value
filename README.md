# มูลค่ายาคืน (Returned Drug Value)

เว็บแอปของห้องยา **โรงพยาบาลปรางค์กู่** ที่มีหน้าที่เดียว — **แปลงยาที่ผู้ป่วยคืนมาให้เป็นตัวเลขเงิน**
แล้วสรุปเป็นตัวชี้วัด (KPI) ให้ผู้บริหารดูได้ทั้งปีงบประมาณ

เปิดเว็บ → พิมพ์ชื่อยา → ใส่จำนวน → กดบันทึก → เห็นมูลค่าที่ประหยัดได้สะสมทั้งปี พร้อมกราฟและปุ่มส่งออกไฟล์

---

## เว็บนี้ทำอะไรได้บ้าง

| หน้า | ทำอะไร |
|---|---|
| **บันทึก** | ค้นยาจาก 417 รายการของโรงพยาบาล กดเลือก ใส่จำนวน เลือกว่าใช้ต่อได้หรือต้องทำลาย แล้วกดบันทึกทั้งรอบทีเดียว |
| **ประวัติ** | ดูรายการที่บันทึกไว้ ค้นด้วยชื่อยาหรือ HN กรองได้ 4 ช่วงเวลา แก้จำนวน/สถานะ หรือลบทีละรายการ |
| **สรุป** | มูลค่าประหยัดสะสมทั้งปีงบ · กราฟแท่ง 12 เดือน (ต.ค.→ก.ย.) · ยา 10 อันดับ · สัดส่วนแหล่งที่มา · ธีมสว่าง/เข้ม · ส่งออกไฟล์ Excel |
| **จัดการราคา** | ใส่ราคาต่อหน่วยของยาแต่ละตัว แก้หน่วยนับ (เม็ด/ขวด/หลอด/…) ถ้าค่าเริ่มต้นไม่ตรง |
| **ตั้งค่า** | ชื่อห้องยา · แหล่งที่มาเริ่มต้น · ยาที่คืนบ่อย 6 ตัว · ธีมสว่าง/เข้ม |

**ยังไม่มีระบบเข้าสู่ระบบ** — เปิดเว็บแล้วใช้ได้เลย (ตามที่เคาะไว้ในเวอร์ชันนี้)

---

## หัวใจของแอป — ราคาถูกแช่แข็ง

ทุกครั้งที่กดบันทึก ระบบจะ **คัดลอกราคา ณ วันนั้นเก็บไว้ในแถวเลย** (`mr_return.unit_price`)
ไม่ได้เชื่อมไปอ่านราคาปัจจุบันตอนแสดงผล

แปลว่า **ถ้าราคายาเปลี่ยนกลางปี ตัวเลข KPI ย้อนหลังจะไม่ขยับ** — เหมือนใบเสร็จที่ออกไปแล้ว
ต่อให้ขึ้นราคาทีหลัง ยอดในใบเสร็จเก่าก็ไม่เปลี่ยน

จุดที่ต้องระวัง: **การแก้ไขรายการเก่า (PATCH) ห้ามแตะราคาเด็ดขาด** แก้ได้แค่จำนวนกับสถานะใช้ต่อ/ทำลาย

## ใช้เทคโนโลยีอะไร

| เรื่อง | ใช้อะไร |
|---|---|
| โครงเว็บ | Next.js 15 (App Router) + React 19 — **JavaScript ล้วน ไม่มี TypeScript** |
| ฐานข้อมูล | Supabase (Postgres) โปรเจกต์ `tb-calculator` — ตัวเดียวกับ TB Calculator และ ME-DRP |
| ตารางของแอปนี้ | `mr_drug_price` · `mr_return` · `mr_setting` (ขึ้นต้นด้วย `mr_` ทุกตาราง) |
| ตารางยา | `public.drugs` 417 แถว — **ของกลาง ห้ามแก้** เพราะอีก 2 เว็บใช้อยู่ |
| ฟอนต์ | Sarabun + IBM Plex Sans Thai ฝังมากับเว็บ (`next/font/google`) ไม่ต้องโหลดจากอินเทอร์เน็ต |
| ขึ้นเว็บจริง | Cloudflare **Workers** (ผ่าน OpenNext) ไม่ใช่ Pages เพราะ Next.js มีฝั่งเซิร์ฟเวอร์ |

## ติดตั้งบนเครื่อง

```bash
npm install
```

คัดลอก `.env.example` เป็น `.env.local` แล้วเติมกุญแจ

```
SUPABASE_URL=https://ryewggkhunpuipgkgbfv.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<เอามาจาก Supabase Dashboard → Project Settings → API → service_role>
```

แล้วสั่ง

```bash
npm run dev
```

เปิด `http://localhost:3000`

> ⚠️ **ห้ามรัน `npm run build` ขณะที่ `npm run dev` ยังเปิดอยู่** โฟลเดอร์ `.next` จะชนกัน แล้วขึ้นข้อผิดพลาด `Cannot find module`

## ความปลอดภัย

- กุญแจ Supabase อยู่ **ฝั่งเซิร์ฟเวอร์เท่านั้น** ไม่มีตัวแปร `NEXT_PUBLIC_*` แม้แต่ตัวเดียว → เปิดดู source ของหน้าเว็บก็ไม่เจอกุญแจ
- ทุกการอ่าน/เขียนฐานข้อมูลผ่าน API route ของ Next.js (`app/api/*`) ที่ใช้ `service_role`
- ทั้ง 3 ตารางเปิด RLS (ระบบกั้นสิทธิ์ข้อมูล) ไว้ **โดยไม่มี policy สักข้อ** = ปฏิเสธทุกคำขอที่เข้าตรงจากภายนอก

## ก่อนขึ้นเว็บจริง เช็คสิ่งเหล่านี้

1. ตั้ง `SUPABASE_URL` และ `SUPABASE_SERVICE_ROLE_KEY` บน Cloudflare (Workers → Settings → Variables) ให้ตรงกับ `.env.local`
2. รันไฟล์ใน `scripts/` ครบทั้ง 3 ไฟล์แล้ว (`001_schema.sql` → `002_functions.sql` → `003_seed_prices.sql`)
3. ใส่ราคายาที่คืนบ่อยจริงในหน้า **จัดการราคา** ก่อน ไม่งั้นตัวเลข KPI จะเป็นศูนย์
4. ล้างข้อมูลทดลองทิ้ง — `delete from mr_return;`

## ที่มา

แปลงมาจากมอคอัปของ Claude Design (`Med Return App.dc.html`) แบบตรงตัวทุกจุด
สี ระยะห่าง ขนาดตัวอักษร โครง DOM เหมือนต้นฉบับหมด

จุดที่ต่างจากมอคอัปโดยตั้งใจ มี 5 อย่าง

1. **ปุ่มลบในหน้าประวัติมีหน้าต่างยืนยัน 1 ชั้น** — มอคอัปกดแล้วลบเลย ของจริงต้องยืนยันก่อน
2. **ตัดเลข "คงคลัง" ออก** — ในมอคอัปเป็นเลขสมมติ ของจริงไม่มีข้อมูลนั้น เหลือแค่หน่วยนับ
3. **ยาที่ยังไม่ใส่ราคายังโผล่ในผลค้นหา แต่ขึ้นป้ายเตือน**
4. **ช่องค้นในหน้าประวัติหน่วง 0.3 วินาที** เพราะยิงไปถามเซิร์ฟเวอร์ (ช่องค้นยาไม่หน่วง เพราะค้นในเครื่อง)
5. **มีหน้าจัดการราคา** ซึ่งมอคอัปไม่มี เพราะมอคอัปใช้ราคาสมมติที่ฝังไว้ในไฟล์
