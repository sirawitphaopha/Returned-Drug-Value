## 💰 เปลี่ยนกติกาใหญ่ — ยาที่ยังไม่ใส่ราคาบันทึกได้แล้ว

พี่กันสั่ง: *"อยากให้กรอกได้ แม้ราคาของยาจะยังไม่เติม"*

เดิม `app.blockNoPrice` กันไม่ให้เพิ่มยาราคา 0 เข้ารายการเลย — เหตุผลตอนนั้นถูกต้อง
เพราะราคาแช่ไว้ในแถว บันทึกตอนราคา 0 แล้วมูลค่าจะค้างเป็น 0

**แต่บริบทเปลี่ยน** — ห้องยาเริ่มใช้จริงทั้งที่ยังใส่ราคาไม่ครบ
การกั้นไว้จึงกลายเป็น "บันทึกงานประจำวันไม่ได้" ซึ่งแย่กว่าตัวเลขที่ยังไม่สมบูรณ์

```js
app.blockNoPrice = () => false;      // ไม่กั้นแล้ว
```

🚨 **แต่แก้แค่นั้นไม่พอ** — เจอว่า `savePrices` **ไม่ได้ตีราคาย้อนหลัง**
ถ้าไม่แก้ด้วย ของที่บันทึกไปตอนยังไม่มีราคาจะค้างเป็น 0 ตลอดกาล

```js
body: JSON.stringify({ items, backfill: true, by: app.state.recorder || '' })
```

ตอนนี้ใส่ราคาปุ๊บระบบเติมย้อนหลังให้เอง แล้วบอกว่าเติมไปกี่แถว
**ไม่ทับแถวที่มีราคาแล้ว** — กฎแช่ราคายังอยู่ครบ ตัวเลข KPI เก่าไม่ขยับ

ป้าย "ยังไม่ใส่ราคา" ยังอยู่ทุกที่ ผู้ใช้ยังเห็นว่าตัวไหนรออยู่

## 🐛 บั๊กวันที่ค้างวันเก่า — อันตรายที่สุดในรอบนี้

**อาการ:** เปิดเว็บวันที่ 25 แต่ช่องวันที่ยังเป็น 10 ส.ค.
= **ยาที่รับคืนวันนี้จะถูกบันทึกเป็นวันเก่าทั้งหมด**

**ต้นเหตุ** — ร่างใน localStorage เก็บ `date` ไว้ด้วย พอกู้ร่างมา `checkDayRollover`
เช็คแค่ `wasToday = (date === today)` ซึ่งเป็นเท็จ (10 ≠ 25) เลยไม่ยอมอัปเดต
เงื่อนไขนั้นตั้งใจกันการทับวันที่ผู้ใช้เลือกเอง **แต่ไม่ได้เผื่อกรณีร่างค้างข้ามวัน**

```js
const isPast = app.state.date && app.state.date < now;   // ← เพิ่ม
app.setState({ today: now, date: (wasToday || isPast) ? now : app.state.date });
```

+ เรียก `checkDayRollover()` ท้าย `boot()` ทันที **ไม่รอตัวจับเวลา 1 นาที**
ไม่งั้นผู้ใช้เห็นวันเก่าค้างนาทีแรกแล้วกดบันทึกไปก่อน

⚠️ ยังเลือกวันย้อนหลังเองได้ปกติ เงื่อนไขนี้ทำงานเฉพาะตอนทวนวันข้ามวัน

## 🐛 ป๊อปยืนยันค้าง

**อาการ:** กด "ยืนยันลบ" แล้วป๊อปไม่ปิด ดูเหมือนกดไม่ติด (จริง ๆ ลบไปแล้ว)

**ต้นเหตุ** — `confirmRun` เรียก `run()` เฉย ๆ ปล่อยให้แต่ละ handler ปิดเอง
`history.js` ปิดเอง แต่ `removeRow` ของหน้าบันทึกลืมปิด

**แก้ — ปิดที่ปุ่มยืนยันจุดเดียว**

```js
app.setState({ confirm: null }, () => c.run());
```

handler ไม่ต้องปิดเองอีก · เพิ่มป๊อปใหม่ทีหลังก็ทำงานถูกทันที
(ตรงกับกฎ "อะไรที่คล้ายกันรวมเป็นระบบกลางตัวเดียว")
