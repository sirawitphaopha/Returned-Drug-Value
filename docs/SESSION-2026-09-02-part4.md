## ① ตัวช่วยกลางทนก้อนที่ไม่ใช่ `Error`

`supabase-js` **ไม่ได้โยน `Error`** แต่โยนก้อน `{ message, code, details, hint }`
`String(e)` จะได้ `[object Object]` — **ร้องแล้วอ่านไม่รู้เรื่อง = เท่ากับเงียบ** แต่หลอกว่าทำเสร็จแล้ว

**3 ตัวใหม่ใน `lib/maskHn.js`** — `errParts` · `errText` · `safeErrLine`

🚨 **วางที่ `maskHn.js` ไม่ใช่ `apiError.js`** เพราะไฟล์นั้น import `next/server`
ฝั่งเบราว์เซอร์เรียกไม่ได้ และตัวร้องฝั่งเบราว์เซอร์ต้องใช้ตัวเดียวกัน

### 🔴 เจอปัญหาที่สกิลเตือนไว้พอดี — รหัสฐานโดนปิดบัง

```
รหัส 23505 · duplicate key   →   รหัส *** · duplicate key      ทดสอบแล้วเกิดขึ้นจริง
```

รหัสของ Postgres เป็นเลข 5 ตัว ตัวปิดบังจับเลข 4 หลักขึ้นไป
`23505` บันทึกซ้ำ · `42P01` ไม่มีตาราง · `23503` ผิดกฎความสัมพันธ์ — **กุญแจดอกแรกของการไล่บั๊ก**

🚨 **ต้องแยก `code` ออกก่อนปิดบัง แล้วค่อยประกอบกลับ** ไม่ใช่ปิดบังทั้งก้อน

## ② `lib/clientLog.js` — ฝั่งเบราว์เซอร์ก็ต้องร้อง

**เว็บนี้มีหลังบ้านครบ แต่ยังมี 6 จุดที่พังเงียบ**
`catch {}` ในโค้ดฝั่งจอ **ทำงานบนเครื่องของเภสัชกร ไม่เคยผ่าน worker เลย** → Workers Logs ไม่เห็น

| จุดที่เคยเงียบ | เกิดอะไรถ้าล้ม |
|---|---|
| `loadServerDrafts` | แถบล็อตค้างไม่ขึ้น โดยไม่มีใครรู้ |
| `syncDrugs` · `pullDrugs` | แก้ชื่อยาที่เว็บอื่นแล้วที่นี่ยังเห็นของเก่า |
| `pullSetting` | รายชื่อ รพ.สต. หายไปเฉย ๆ |
| `refreshFy` (2 จุด) | ตัวเลขยอดสะสมค้างของเก่า |

### 🚨 catch ที่กลืนเงียบ "ถูกต้อง" มีจริง — เหลือไว้ 3 จุดโดยตั้งใจ

`localStorage` · `setSelectionRange` · `navigator.vibrate` — เป็นความสามารถของเครื่องล้วน ๆ
**เกณฑ์: ทุกอย่างที่คุยกับเซิร์ฟเวอร์ต้องร้อง**

### 🔴 ตัวตรวจฟ้องตัวช่วยกลางตัวใหม่เอง

`api-log-check` รอบแรกฟ้อง `clientLog.js` ว่ามี `console.error`
**ตัวตรวจที่ฟ้องผิดแย่กว่าไม่มีตัวตรวจ** เพราะคนแก้จะไปปิดเสียงตัวช่วยกลางทิ้ง
ซึ่งตรงข้ามกับเจตนาทั้งข้อ · แก้ให้ยกเว้นตัวช่วยกลางทั้งสองตัวแล้ว
