### 2. แก้บั๊ก 41 จุด

กลุ่มที่หนักที่สุด (ทำให้ตัวเลขในฐานข้อมูลผิดจริง)

1. กดบันทึกตอนเน็ตช้า แล้วพิมพ์ยาเพิ่มระหว่างรอ → **ยาตัวนั้นหายเงียบ**
2. ส่งไม่สำเร็จแล้วรีเฟรช → กดบันทึกใหม่ **ได้ข้อมูล 2 ชุด**
3. พิมพ์ปีผิดเป็น 3026 → บันทึกสำเร็จ แต่แถวหายจากทุกหน้าจอ ลบก็ไม่ได้
4. เน็ต รพ. แบบ "ต่ออยู่แต่ไม่ไปไหน" → ปุ่มค้างว่ากำลังบันทึกตลอดกาล
5. เปิดจากมือถือในวงแลน (`http://192.168...`) → ปุ่มบันทึกกดแล้วเงียบสนิท
6. **ทุกข้อผิดพลาดขึ้นว่า "เน็ตหลุด"** กดลองใหม่วนไม่จบ
7. พิมพ์จำนวน 2.5 กลายเป็น 25 (ผิด 10 เท่า)

## 🔑 การตัดสินใจสำคัญที่พี่กันเคาะ

1. **ช่องผู้บันทึกอยู่ในแผงข้าง ไม่ใช่ป๊อปอัป** — แคลร์ทำเป็นป๊อปอัปตอนกดบันทึกก่อน
   แต่พี่กันชี้ว่า *"ทำไมไม่อยู่ตรงนี้ ถัดจากวันที่ ก็ให้มันเลือกตรงนี้ไปเลย"*
   → ย้ายมาอยู่ใต้ วันที่/HN · เลือกครั้งเดียวค้างทั้งเวร · **ป๊อปอัปลบทิ้ง**
2. **ปุ่มเพิ่ม + ชิปเลือกเปลี่ยนจากดำเป็นเขียวเทล** — และเปลี่ยนให้เหมือนกันทุกที่ในเว็บ
3. **วันหมดอายุ กับ สถานะรอตรวจสภาพ — ยังไม่เอา** — เหตุผล: *"เราอยากให้มันง่ายในการกรอก"*
   เก็บเข้า [ROADMAP.md](ROADMAP.md) ไว้แล้ว
4. **ชื่อ Worker บน Cloudflare = `returndrug-pkh`** — แก้ `wrangler.jsonc` ให้ตรง
   ไม่งั้น deploy จากเครื่องจะสร้างโปรเจกต์ใหม่อีกอัน
5. **ไม่เปลี่ยนชื่อบัญชี workers.dev** — เพราะจะกระทบเว็บอื่นทั้งบัญชี
