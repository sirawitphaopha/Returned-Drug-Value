## 3. 🚨 บั๊กหนักที่แคลร์ทำเอง — หน้าเว็บหดไป 347px

พี่กันทักว่า *"กรอบสีขาวมันควรกินพื้นที่ให้ครบเลยไหม"* แคลร์แก้ให้กรอบยืดเต็มความสูง
โดยเปลี่ยนกล่องครอบใน `shell.jsx` เป็น flex คอลัมน์ → **หน้าเว็บหดจาก 1360 เหลือ 1013px ทันที**

**ต้นเหตุ:** กล่องนอกสุดของทุกหน้าใช้ `max-width:1400px;margin:0 auto` จัดกึ่งกลาง
พอพ่อกลายเป็น flex ตัว `margin:auto` บนแกนขวางจะ **ยกเลิกการยืดเต็มความกว้าง** แล้วย่อลงเท่าเนื้อหาแทน
ไม่มี error ไม่มีคำเตือน หดเงียบ ๆ

**วิธีแก้:** ใส่ `width:100%` ให้กล่องนอกสุดของทุกหน้า ทั้งฝั่งคอมและฝั่งมือถือ
เขียนเป็นกฎเหล็กข้อ 13 กับหัวข้อ 3.1 ใน CLAUDE.md แล้ว

หลังแก้: ทั้ง 3 แท็บกว้าง **1360 เท่ากันหมด** (เดิมพี่กันทักว่า "ขนาดของเพจไม่เท่ากันเลยยย")

## 4. ตรึงหน้าจอ — พี่กันสั่ง 2 หน้า

**หน้าบันทึกคอม** — *"มันจะเลื่อนได้แค่ตรงกรอบ ยังไม่มีรายการในครั้งนี้"*
ล็อกความสูงเท่าจอ ทั้งหน้าไม่เลื่อน · ช่องกรอกยา · ยาที่คืนบ่อย · หัวคอลัมน์ · แผงขวา ตรึงหมด

จุดที่ยาก: ทำครั้งแรกแล้วไม่ได้ผล กรอบยังยืดตามจำนวนแถว วัดได้ว่ากรอบสูง 700px บนจอ 640px
**ต้นเหตุ:** กล่องครอบใน `shell.jsx` เป็น `flex:1 0 auto` = ห้ามหด → ความสูงไม่แน่นอน → กรอบข้างในไม่รู้ว่าตัวเองสูงได้แค่ไหน
**แก้:** เพิ่ม `V.fitScreen` สลับกล่องครอบเป็น `flex:1;min-height:0` เฉพาะหน้าบันทึกแบบคอม

**หน้าประวัติคอม** — ตรึงแถบกรอง (`.hist-head`) + หัวคอลัมน์ (`.sticky-head`)
ระยะที่หัวคอลัมน์ต้องติดวัดสดด้วย **ResizeObserver** เขียนลงตัวแปร `--histhead`
ตั้งเลขตายตัวไม่ได้เพราะแถบกรองขึ้นบรรทัดใหม่เองเมื่อจอแคบ

*"ตอนกดดูเดโม่ ตรง copyright มันทับกับรายการ"*

ไล่วัดกรอบทับกันครบ **6 แบบ** (บันทึก/ประวัติ/สรุป × คอม/มือถือ) ในโหมดตัวอย่าง → **ทับ 0 จุดทุกแบบ**
เดาว่าเกิดตอนที่โค้ดค้างอยู่ครึ่งทาง ช่วงที่เนื้อหาหดเหลือ 1013px แต่ท้ายเว็บยังกว้าง 1320px
**รอพี่กันยืนยันหลังรีเฟรชแรง ถ้ายังเจอต้องขอภาพหน้าจอ**
