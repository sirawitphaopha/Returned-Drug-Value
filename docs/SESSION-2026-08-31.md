## 2. อัปเดตสดข้ามเครื่อง

พี่กันสั่ง: *"ถ้าเราเปิดตารางประวัติ แล้วมีอีกคนส่งข้อมูลมา มันจะขึ้นอัปเดตให้เราเลย"*

**วิธี** ถามหลังบ้านทุก 20 วินาทีว่าลายเซ็นเปลี่ยนไหม ตอบกลับแค่ตัวเลข 4 ตัว
เปลี่ยนเมื่อไหร่ค่อยดึงของจริงเฉพาะหน้าที่เปิดอยู่

**ไม่ต่อฐานข้อมูลตรงจากเบราว์เซอร์** เพราะต้องเอากุญแจไปไว้ในเบราว์เซอร์
= ใครเปิดเว็บก็แก้ข้อมูลได้ ขัดกฎเหล็กข้อ 6 · แนวเดียวกับที่คลังยาใช้อยู่แล้ว

### 🚨 ต้องมีร่องรอยเวลาในฐาน ไม่ใช่แค่นับแถว

`scripts/016_rev_signature.sql` เพิ่ม `mr_return.updated_at` + trigger

การนับแถวจับได้แค่ **เพิ่ม** กับ **ลบ** — จับ "แก้จำนวน" หรือ "สลับใช้ต่อเป็นทำลาย"
ไม่ได้เลย ซึ่งเป็นการแก้ที่กระทบมูลค่าโดยตรง เครื่องอื่นต้องเห็นทันที

trigger ทำงานในฐานข้อมูล จึงจับได้แม้แก้ตรงในหน้า Supabase
(แนวเดียวกับ `drug_audit` ของตาราง `drugs`)

### 🚨 ต้องแยกให้ออกว่าใครเป็นคนแก้

ถ้าไม่แยก กดบันทึกเองแล้วจะเด้งข้อความ "มีข้อมูลใหม่จากเครื่องอื่น" ทุกครั้ง

`app.invalidate()` ประทับ `_ownAt` ไว้ แล้วยิง `pulse({quiet:true})` ตามหลัง 1.2 วินาที
เพื่อจำลายเซ็นชุดใหม่ทันที · เผื่อเวลา **45 วินาที** ไม่ใช่ 20
เพราะตัวจับเวลาถามทุก 20 ถ้าเผื่อเท่ากันจะชนขอบพอดี แล้วเด้งผิดบ้างไม่ผิดบ้าง
ซึ่งเป็นบั๊กที่จับยากที่สุดแบบหนึ่ง

### 🚨 แท็บที่ซ่อนอยู่ไม่ถาม

คอมห้องยาเปิดเว็บค้างทั้งวันโดยไม่ได้มอง ถามตลอดจะได้คำขอเปล่าวันละสองพันกว่าครั้งต่อเครื่อง
กลับมาที่แท็บเมื่อไหร่ถามทันที

## 4. เลิกคำนวณค่าของหน้าที่ไม่ได้เปิด

**ผลวัดก่อนแก้** — พิมพ์ 1 ตัวอักษรในช่องค้นยา

```
catalog   1.81 ms ต่อครั้ง   ← มากกว่าทุกหน้ารวมกัน
record    0.27 · lots 0.28 · summary 0.22 · history 0.19 · shell 0.14
```

**ทำ 2 อย่าง**

1. `memo1()` จำผลการประกอบชื่อยา 417 ตัว → 1.81 เหลือ 0.93 ms
2. `vals/index.js` → `need` คำนวณเฉพาะหน้าที่เปิดอยู่ → เหลือ 0.35 ms รวมทุกไฟล์

**เร็วขึ้น 7 เท่า**

### 🚨🔴 กับดักที่เกือบพัง — ธงอยู่ในไฟล์ที่กำลังจะข้าม

`isPrices` `isLots` `isCatalog` เดิมอยู่ในไฟล์ของหน้าตัวเอง
ซึ่งกลายเป็นวงจรอุบาทว์ทันทีที่ข้าม — **ไม่คำนวณหน้าราคา → ไม่มีธง → กดเข้าหน้าราคาแล้วจอว่างถาวร**

ต้องเติมธงพวกนี้ใน `vals/index.js` เสมอ

🚨 **หน้าที่ถูกข้ามได้ค่าเป็นว่างเปล่า ห้ามคืนค่าเก่าที่จำไว้**
ธงอย่าง `slipOpen` จะค้างเป็นจริง แล้วใบสรุปจะเด้งขึ้นมาเอง

🚨 **ตรวจก่อนตัดทุกครั้ง** — เขียนสคริปต์ไล่ดูทั้ง 334 คีย์จาก 6 ไฟล์
ยืนยันว่าไม่มีหน้าไหนใช้ค่าข้ามไฟล์กันเลยสักตัว **แล้วค่อยตัด**

## 5. คลังยาวาดครบ 417 แถว แต่ทยอยตามที่เลื่อนถึง

พี่กันสั่ง: *"ก9 เราอยากวาดครบ 417 แต่ส่วนที่ไม่แสดงก็ไม่เรนเดอร์"*

| กล่องในหน้า | 8,543 | **1,366** |

### ⚠️ สองวิธีที่ลองแล้วไม่ช่วย — วัดจริงทั้งคู่ ห้ามเสียเวลาซ้ำ

## 6. ตาข่ายกันโค้ดแปลกปลอม

CSP ย้ายจาก `next.config.js` ไปออกที่ `middleware.js` **รายคำขอ**
เว็บจริงได้ `script-src 'self' 'nonce-xxx' 'strict-dynamic'` — **ไม่มี `unsafe-inline` แล้ว**

### 🔴 บทเรียนใหญ่ที่สุดของรอบนี้ — เว็บจริงจอขาว

เทสใน dev ผ่านหมด แต่พอ build เป็นเว็บจริงแล้ว **สคริปต์ถูกบล็อกทั้งหมด จอขาวทั้งใบ**

**ต้นเหตุ** หน้า `/` กับ `/login` เป็นหน้าที่ Next สร้างล่วงหน้าตอน build
จึงได้ HTML ก้อนเดิมที่ไม่มีใบอนุญาตติดมา

**แก้** `export const dynamic = 'force-dynamic'` ทั้งสองหน้า
· `app/page.js` ใส่ตรง ๆ · `app/login/` ต้องใส่ที่ `layout.js` (หน้านั้นเป็น client component)

🚨🔴 **แตะเรื่อง CSP เมื่อไหร่ ต้องเทส production build เสมอ**
ตอนรันในเครื่องมี `'unsafe-eval'` อยู่ จึงไม่มีทางเจอปัญหานี้เลย

```bash
npm run build && npx next start -p 3000
```

1. เข้าหน้าประวัติ รอให้ขึ้นครบ แล้วกด **F5** — ต้องขึ้นทันที ไม่มีโครงจางแวบ
2. **เปิด 2 หน้าต่าง** ไว้หน้าประวัติทั้งคู่ → บันทึกที่หน้าต่างแรก → อีกหน้าต่างต้องขึ้นเองใน 20 วินาที

4. เข้าหน้าคลังยาแล้วเลื่อนลงจนสุด — ต้องได้ครบ 417 ตัว
5. ปิดแท็บแล้วเปิดใหม่ — ต้องโหลดใหม่หมดเหมือนเดิม
