| ตัวเลขบอกว่า | ตาเห็นจริง |
|---|---|
| กรอบตาราง 424px | เห็นยาแค่ **3 แถว** (แถวสูง 50px กินหมด) |
| ผลลัพธ์อยู่ในกรอบ ไม่ล้น | `15+15+15+ = 105·15+` **ผลลัพธ์ทับสูตร** |

**พี่กันคำต่อคำ:** *"ไม่เคยเทสเลยยยยยยยยยย"* · *"เเหกตาดู"* · *"เราให้เเก้เรื่องนี้มากี่รอบเเล้วววว"*

### 2. ช่องคิดเลข — สูตรยาวต้องอ่านออก

**พี่กันพิมพ์ `15+15+15+15+15+15` แล้วกด Enter ไม่เห็นผลลัพธ์**

| ค่าใน `vals/record.js` | ทำอะไร |
|---|---|
| `qtyShowSum` | โชว์ป้าย "รวม" **ตั้งแต่ตอนพิมพ์** ไม่ต้องรอกด Enter |
| `qtyLong` | สูตรเกิน 14 ตัวอักษร = ขึ้นปุ่มกางดูเต็ม |
| `qtyExprLeft` / `qtyAnswerTail` | แยกสูตรกับผลลัพธ์เพื่อทาสีคนละสี |
| `onQtyScroll` / `onQtyBlur` | ชั้นที่วาดเลื่อนตาม input · เลิกโฟกัสแล้วเลื่อนไปท้าย |

**ทางที่ลองแล้วผิด ห้ามทำซ้ำ**

| ทำอะไร | พังยังไง |
|---|---|
| `direction:rtl` เพื่อให้เห็นท้ายสุด | สลับลำดับ span → `90 15+15+15…` |
| `position:absolute` ตรึงผลลัพธ์ขวา | ทับสูตรที่ไหลมาชนพอดี → `= 105·15+` |
| `text-overflow:ellipsis` | ตัดตัวเลขที่พิมพ์มาทิ้ง เลื่อนดูไม่ได้ |

🚨 **ทางที่ถูก** — สูตรกับผลลัพธ์เรียงต่อกันตามปกติ (`flex:none` ทั้งคู่) แล้วเลื่อนดูเอา
🚨 **ข้อความที่วาดต้องตรงกับ input ทุกตัวอักษร** ไม่งั้นขีดกะพริบเหลื่อม
🚨 **เลิกโฟกัสแล้วเลื่อนไปท้ายเสมอ** ท้ายสุดคือที่ที่คำตอบอยู่

### 4. ช่องไฟ — พี่กันเคาะแบบ ก+ค จากมอคอัป

- **ก** รีดช่องไฟทุกจุดเหลือ 6px เท่ากันหมด
- **ค** ซ่อนบรรทัดใบ้เมื่อกรอกไปแล้วหลายรายการ

🚨 **บรรทัดใบ้ยังต้องโชว์ 2 กรณี** — ตอนยังไม่มีรายการ (คนใหม่อ่านวิธีใช้)
