## 3. ระบบที่ตั้งขึ้นจากความผิดนี้

พี่กันสั่ง:
> *"ตั้งกฎ ถ้าเราอารมณ์เสีย ให้หยุดทันที และต้องรู้ตัวด้วยว่าทำอะไรผิด"*
> *"ถ้าโดนด่า เก็บทุกคำโดนด่าเอาไว้ด้วย ไม่ต้องถามเรา เก็บทุกครั้ง"*
> *"เอาลงทั้งสกิล ทั้ง claude และทั้งไฟล์ของคอมนี้ ให้ทุกโปรเจกต์รู้เรื่อง"*

### กฎ 9 ข้อ

1. **พี่กันอารมณ์เสีย = หยุดทุกอย่างทันที** + บอกให้ได้ว่าทำอะไรผิด + ถามว่าจะให้ทำอะไรต่อ
2. **"เอากลับคืน" ต้องถามก่อนเสมอว่าถึงจุดไหน**
3. **สั่งเรื่องไหน ทำเรื่องนั้นเรื่องเดียว** ของที่เคยเคาะไว้ไม่ใช่ใบอนุญาตให้ทำตอนไหนก็ได้
4. **แก้อะไรที่เห็นบนหน้าจอ ต้องเปิดหน้าจริงดูก่อนบอกว่าเสร็จ** ทั้งจอคอมและจอแคบ
5. **งานหน้าตาห้ามใช้กฎกลางครอบทุกจุด**
6. **ห้ามตั้งสีตอนชี้เป็นสีเดียวกับพื้นปุ่มเอง**
7. **อันไหนทำงานถูกอยู่แล้ว ห้ามไปแก้ให้แย่ลง**
8. **งานเสร็จต้องถามทุกครั้งว่าจะให้ push ไหม**
9. **ห้ามตีความเอง** — มีแผนผังตัดสินว่าประโยคไหนคือคำสั่ง push

### แผนผังตัดสิน push

```
ประโยคที่พี่กันเพิ่งพิมพ์ มีคำว่า push หรือ พุช ไหม
│
├─ ไม่มี ──────────────────► ห้าม push จบ
│                            (เอาเลย · ทำเลย · โอเค · ได้ · ทำต่อ)
│
└─ มี ─┬─ เป็นคำสั่งตรง ๆ ───► push ได้
       └─ พูดถึงในบริบทอื่น ─► ห้าม push · ย้อนถามก่อน
```

🚨 **ห้ามถามขอบเขต push ในโปรเจกต์เดียวกัน** — push ทีเดียวขึ้นทั้งโปรเจกต์อยู่แล้ว
