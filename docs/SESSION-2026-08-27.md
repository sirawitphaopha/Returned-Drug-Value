## 1. งานที่ทำเสร็จ

### 1.1 ปุ่ม "ทำลาย" — ตัวที่ตกหล่นจริง

พี่กันถามไว้ตั้งแต่ต้นว่า **"ทำลาย สีแดงไหม"** แคลร์ตอบว่าทำแล้ว **ซึ่งผิด**

ที่ตรวจเจอตอนนั้นคือชิปในแถวรายการ (`hv-des-on` / `hv-des-off`) ซึ่งแดงถูกต้องอยู่แล้ว
จุดที่พลาดคือ **ปุ่มในช่องกรอกด้านบน** อันที่พี่กันส่งรูปมาให้ดู

```jsx
// components/pages/record.jsx บรรทัด 377
className={V.pendReuseOn ? 'hv-txt'  : 'hv-des-off'}   // ❌ hv-txt เป็นเขียว
className={V.pendReuseOn ? 'hv-del'  : 'hv-des-off'}   // ✅ พื้นแดงจาง ตัวหนังสือแดงอิฐ
```

ไล่ตรวจทุกจุดที่มีชิปใช้ต่อได้/ทำลายแล้ว — `record` 3 จุด · `sheet` 1 · `lotedit` 1
เหลือจุดนี้จุดเดียวที่ผิด

### 1.2 ปุ่มบันทึกตอนยังไม่เลือกยา — ครีมอมเหลือง + สั่น

พี่กันสั่ง *"ไม่ชอบสีเทา ปุ่มนี้ขออนิเมชั่นแปลก ๆ ไม่เหมือนเพื่อน"*

| | เดิม | ใหม่ |
|---|---|---|
| พื้น | เทา `#e9ebe8` | ครีมอ่อน `#fdf6e9` |
| ตัวหนังสือ | เทา `#6f7873` | อำพัน `#96650f` |
| ขอบ | ไม่มี | อำพันจาง |
| ตอนชี้ | เทาเข้มขึ้นนิดเดียว | ครีมเข้มขึ้น + **สั่นซ้ายขวา 0.42 วินาที** |

**ทำไมเลือกครีมอมเหลือง** — เป็นโทนอำพันที่เว็บใช้อยู่แล้ว (ความเข้มข้น % · แถบโหมดดูตัวอย่าง)
และไม่ใช่เขียวซึ่งจะหลอกว่าปุ่มพร้อมกด

**ทำไมเลือกการสั่น** — ไม่มีปุ่มอื่นในเว็บทำแบบนี้ ตรงกับที่พี่กันขอว่า "ไม่เหมือนเพื่อน"
และสื่อความหมาย "ยังไม่ได้นะ" ที่คนไทยคุ้นจากมือถือ

🚨 **ปุ่ม "เพิ่ม" ที่ใช้ `hv-off` อยู่ไม่ถูกแตะ** เพราะพี่กันชี้ปุ่มเดียว

### 1.3 ปุ่มธีม สว่าง / เข้ม — แอนิเมชันโดยไม่แตะสี

พี่กันสั่งไว้ก่อนว่าปุ่มคู่นี้**ไม่ต้องเปลี่ยนสี** แล้วสั่งเพิ่มรอบนี้ว่า *"ขออนิเมชั่นสองปุ่มนี้"*

| ปุ่ม | ตอนเอาเมาส์ชี้ |
|---|---|
| **สว่าง** | แสงอุ่นสีทองเปล่งจากกลางปุ่มออกไปรอบ ๆ แล้วจางหายเอง |
| **เข้ม** | ผืนมืดคืบเข้ามาจากขวา แล้วมีดาว 5 ดวงขึ้นตามก่อนจางหาย |

🚨 **แอนิเมชันต้องจางหายเมื่อจบ ห้ามค้าง** — ชั้นที่ค้างอยู่ก็คือการเปลี่ยนสีถาวรนั่นเอง
รอบแรกทำเป็น `forwards` (ค้างไว้) แล้วพบว่าขัดคำสั่งเดิม จึงแก้ให้กลับสู่สภาพเดิมทั้งคู่
ตรวจแล้วสีพื้นกับสีตัวหนังสือไม่เปลี่ยนเลยทั้งก่อนและหลังชี้

🚨 **ดาวใช้ `currentColor`** — ปุ่มคู่นี้มี 4 ชุดสีตามธีมที่เลือกอยู่
ใช้สีตัวหนังสือของปุ่มนั้นจึงตัดกับพื้นเสมอไม่ว่าธีมไหน

**พี่กันเลือกจากมอคอัป 4 แบบ** (`public/theme-anim.html`) — เคาะ **แบบ ก**

⚠️ **มอคอัปรอบแรกกับโค้ดจริงไม่ตรงกัน 3 จุด** เพราะแคลร์แก้โค้ดหลังทำมอคอัปแต่ไม่ได้อัปเดตไฟล์
(แสงค้าง → จางหาย · เงาจางเกินจนมองไม่เห็น → เข้มขึ้นเท่าตัว · ดาว 4 ดวงเล็ก → 5 ดวงใหญ่ขึ้น)
แก้ให้ตรงกันทุกบรรทัดแล้ว **บทเรียน: มอคอัปที่ส่งให้ดูต้องตรงกับโค้ดจริงเสมอ**

### 1.4 แถบเตือนโหมดดูตัวอย่าง

ตัวสุดท้ายในเว็บที่ยังไม่มีสีตอนชี้ — พื้นส้ม `#d68a2a` → `#c2761c`

ไม่ใช้ `.hv-amber` ที่มีอยู่แล้วเพราะเป็นน้ำตาลเข้ม `#92400e` กระโดดจนดูเหมือนคนละแถบ

### 1.5 เส้นแบ่งคอลัมน์ + ไฮไลต์แถว หน้ารายการ Lot

พี่กันสั่ง *"ทำแบบตาราง excel นี่มันยากนักเหรอ"*

```css
.col-head > span, .col-row > span {
  align-self: stretch !important;      /* 🚨 ต้องมี !important */
  display: flex; align-items: center;
}
.col-head > span:not(:last-child),
.col-row > span:not(:last-child) { border-right: 1px solid rgba(30,36,32,.06); }
.col-row:hover { background: #eef6f1 !important; }
.col-row:hover .hv-cream { background: #fbeed4 !important; }
.col-row:hover .hv-bg-f6 { background: #e8f2ec !important; border-color: rgba(47,125,93,.30) !important; }
.col-row:hover .hv-teal  { background: #24614a !important; }
```

🚨 **ต้องมี `!important`** — แถวเขียน `align-items:center` ฝังในแท็ก ซึ่งชนะกฎในไฟล์ CSS เสมอ
ช่องจึงสูงแค่ 34px ในแถวที่สูง 53px เส้นแบ่งเลยขาดเป็นช่วง ๆ ลอยกลางแถว

🚨 **ปุ่มในแถวต้องเปลี่ยนสีตามแถวด้วย** แต่ละปุ่มเข้มขึ้นในโทนของตัวเอง ไม่ใช่โทนเดียวกันหมด

## 2. เครื่องมือตรวจ — ของเดิมรายงานไม่ตรง

### `hover-check.mjs` — เปลี่ยนจากเทียบภาพเป็นอ่านค่าสี

**อาการ:** รันสองรอบได้คำตอบคนละอย่าง รอบหนึ่งฟ้องปุ่มกลับ อีกรอบฟ้องชิปแหล่งที่มา

**ต้นเหตุ:** ถ่ายภาพปุ่มก่อน/หลังชี้มาเทียบไบต์ต่อไบต์ โดยรอแค่ **0.045** กับ **0.16 วินาที**
ทั้งที่การไล่สีของเว็บใช้เวลา **0.12–0.15 วินาที** ภาพจึงถ่ายติดตอนสียังไหลไม่ถึงที่

**แก้:** อ่านค่าสีที่เบราว์เซอร์คำนวณจริง (`getComputedStyle`) แทน + รอ 0.42/0.62 วินาที
หลังแก้ ผลนิ่ง 2 รอบติด — **160 ปุ่มเปลี่ยนสีครบทุกตัว**

🚨 **ตัวตรวจที่รายงานผิดแย่กว่าไม่มีตัวตรวจ** ให้ความมั่นใจแบบผิด ๆ แล้วไล่หาสาเหตุผิดทาง

### `hue-check.mjs` — ไฟล์ใหม่ ตรวจว่าสี "ถูกโทน" ไหม

ตัวเดิมเช็คได้แค่ **"เปลี่ยนไหม"** — ปุ่มแดงที่ชี้แล้วเป็นเขียวจึงผ่านของมัน เพราะสีเปลี่ยนจริง
**นี่คือเหตุผลที่ปุ่มทำลายรอดสายตามาได้**

ตัวใหม่เทียบ **เฉดสีบนวงล้อ** — ต่างเกิน 40 องศา = คนละโทน
รายงานเป็น**ชื่อสีภาษาไทย** ไม่ใช่รหัสสี (พี่กันสั่งไว้ว่า *"เรามองเห็นสีเหรอ"*)

🚨 **มีจุดบอดที่ตัดสินแทนคนไม่ได้** — ปุ่มที่ตอนปกติเป็นขาว/เทาไม่มีโทนให้เทียบ
จึงแยกออกมาเป็นรายการ **"ต้องอ่านเอง"** แทนที่จะเดา
ต้องตัดสินจาก**ความหมายของปุ่ม** (ทำลาย=แดง · บันทึก=เขียว · รอ=อำพัน)

ผลตรวจ **233 ปุ่ม — ไม่มีตัวไหนผิดโทน**

**และทำเว็บพัง 3 ครั้ง** จากการวางคอมเมนต์ JSX ผิดที่

### 🔴🔴 บทเรียนใหญ่ที่สุด

> *"ตอนตรวจทาน ตรวจแบบให้เธอเป็นผู้ใช้โว้ย ปล่อยผ่านมาได้ไง"*

แคลร์ตรวจแบบ **"โค้ดทำงานไหม"** แทนที่จะตรวจแบบ **"มันสวยไหม ใช้ได้ไหม"**
เห็นภาพว่าคอลัมน์เปลี่ยนสีก็บอกว่าทำงานแล้ว ทั้งที่แถบสีเป็นก้อนลอยดูเละ

### บทเรียนเทคนิค 4 ข้อ

🚨 **คอมเมนต์ CSS ที่ปิดเกินหนึ่งตัว ฆ่ากฎทุกข้อที่เหลือในไฟล์**
แก้กี่รอบเว็บก็ไม่เปลี่ยน แล้วไล่หาสาเหตุผิดทางไปเรื่อย
**ตรวจด้วยการนับ** — จำนวน `/*` ต้องเท่ากับ `*/` เป๊ะ

🚨 **เปลี่ยน `display` เป็น `flex` ทำให้ `text-align` ไม่มีผลทันที**
ตัวเลขที่เคยกึ่งกลาง/ชิดขวาไหลไปชิดซ้ายหมด **โดยไม่มี error อะไรเลย**
ต้องเพิ่ม `justify-content` คู่กับ `text-align` เดิมทุกช่องที่ไม่ได้ชิดซ้าย

🚨 **คอมเมนต์ JSX `{/* */}` วางได้เฉพาะตำแหน่งที่รับ element**
วางในแอตทริบิวต์ · หลัง `) : (` · ในบล็อก `.map()` ที่คืนค่าเดียว = เว็บพังทันที

🚨 **สไตล์ฝังในแท็กชนะกฎ CSS เสมอ** ต้อง `!important` แล้ว**วัดค่าจริงในเบราว์เซอร์**
