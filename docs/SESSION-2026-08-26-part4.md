## 1. ใบสรุป Lot — เอกสารราชการที่สร้าง PDF ได้จริง

### 🔴 บั๊กใหญ่ที่หาอยู่นาน — พิมพ์แล้วได้หน้าเว็บทั้งหน้า

กฎการพิมพ์เดิมเขียนไว้ว่า

```css
body > * { display: none !important; }
body > div:has(.slip-paper) { display: block !important; }
```

**Next.js ห่อทั้งเว็บไว้ในกล่องเดียวที่เป็นลูกชั้นแรกของ `body`**
บรรทัดที่สองจึงไปตรงกับกล่องที่ครอบทั้งเว็บ แล้วเปิดหน้าเว็บกลับมาทั้งหน้าในกระดาษ

เสียเวลาไล่หาอยู่นานเพราะเข้าใจผิดว่าเป็นเรื่องเบราว์เซอร์ไม่รองรับ `:has()`
**ที่จริงตัวเลือกทำงานถูกทุกอย่าง แค่ไปตรงกับของผิดตัว**

**วิธีแก้** — ย้ายใบไปแขวนที่ `body` โดยตรงด้วย `createPortal`
แล้วกฎการพิมพ์ชี้ไปที่ `.slip-backdrop` ตรง ๆ ได้เลย ไม่ต้องเดาโครงกล่องอีก

### เรื่องที่ตามมาหลังแก้บั๊กหลัก

| อาการ | ต้นเหตุ | แก้ที่ |
|---|---|---|
| แถบเทาก้นกระดาษ | กระดาษสูงเท่าเนื้อหา ส่วนที่เหลือเห็นพื้นหลังเว็บ | `html, body { background:#fff }` ตอนพิมพ์ |
| ชื่อ รพ.สต. ยาวจนหัวเอกสารสองฝั่งไม่ตรงกัน | ยัดลงคอลัมน์แล้วตกบรรทัด | ย้ายเป็นบรรทัดเต็มความกว้าง (`.sp-site`) |

### ระบบชื่อเต็ม รพ.สต.

**ในเว็บใช้ชื่อสั้น (กู่ · ตูม) แต่ในใบพิมพ์ใช้ชื่อเต็มตามทะเบียน**
เพราะใบนี้ถูกส่งกลับไปให้ รพ.สต. ต้นทางเก็บเป็นหลักฐาน

- คอลัมน์ใหม่ `mr_setting.pcu_full` เป็น map ชื่อสั้น → ชื่อเต็ม ครบ 13 แห่ง
- ไฟล์ `scripts/015_pcu_full.sql` (รันผ่าน MCP แล้ว)
- ไม่มีใน map ให้เติมคำนำหน้า `โรงพยาบาลส่งเสริมสุขภาพตำบลบ้าน` เป็นค่าสำรอง

## 2. หน้ารายการ Lot — ตารางที่ค้น กรอง เรียงได้

### โครงใหม่ 9 คอลัมน์

```
วันที่ · เลข Lot · ผู้บันทึก · แหล่งที่มา · รพ.สต. · รายการ · ใช้ต่อได้ · ทำลาย · จัดการ
```

- **หัวคอลัมน์กดเรียงได้ทุกคอลัมน์** (ยกเว้นจัดการ) ใช้ท่าเดียวกับหน้าประวัติเป๊ะ ๆ
- **ช่องค้น** — เลข Lot · ชื่อผู้บันทึก · ชื่อ รพ.สต. พิมพ์หลายคำได้
- **ตัวกรองเลือกสองชั้น** — แหล่งที่มา แล้วถ้าเป็น รพ.สต. ค่อยเลือกว่าแห่งไหน
- **ตัวนับกับยอดรวมนับจากผลที่กรองแล้ว** — กรองแห่งหนึ่งแล้วรู้ทันทีว่าเป็นเงินเท่าไร
- จอแคบยังเป็นการ์ดเหมือนเดิม แต่มีช่องค้นกับตัวกรองครบ

### 🔴 สามรอบที่แคลร์ทำผิดแล้วพี่กันสั่งแก้

| แคลร์ทำ | ทำไมผิด | ที่ถูก |
|---|---|---|
| ดึงรายชื่อ รพ.สต. จากที่โผล่ในข้อมูล | ยังไม่มีล็อตไหนกรอกชื่อแห่ง รายการเลยว่างทั้งหมด | ดึงครบ 13 แห่งจากการตั้งค่า |
| ย่อปุ่มเหลือแต่ไอคอน | ไอคอนเปล่าต้องเดาความหมาย คนใช้ไม่บ่อยไม่กล้ากด | มีข้อความกำกับทุกปุ่ม |
| ยัดทั้ง 13 แห่งลงดรอปดาวน์เดียว | รายการยาวเป็นหางว่าว 19 บรรทัด | เลือกสองชั้น |

**บทเรียนร่วมของทั้งสามข้อ** — แคลร์ตัดสินใจแทนผู้ใช้ด้วยเหตุผลเรื่อง "ประหยัดที่บนจอ"
ทั้งที่ของที่ประหยัดไปคือสิ่งที่ทำให้ใช้งานได้จริง

### 🔴 `background:#fff` แบบรวบล้างลูกศรของช่องเลือกทิ้ง

กฎกลางใน `globals.css` วาดลูกศร ▾ ด้วย `background-image` คู่กับ `appearance:none`
เขียน `background:#fff` แบบรวบในสไตล์ฝังในแท็ก = ล้างรูปลูกศรทิ้งทั้งหมด
**ต้องเขียน `background-color` แยกเสมอ** — ตระกูลเดียวกับบั๊ก `border-color` เดี่ยวใน hover ของ ME-DRP

🔴 **บทเรียนเรื่องเครื่องมือ: heredoc ของ Bash กินเครื่องหมายทับกลับ**

เขียนอักขระขึ้นบรรทัดใหม่ (ทับกลับ + n) ลงไฟล์ผ่าน heredoc แล้วมันกลายเป็น
การขึ้นบรรทัดจริงในไฟล์ ทำให้ข้อความในโค้ดขาดกลาง `lib/csv.js` พังทั้งไฟล์
เว็บขึ้น Build Error ทันที: `Unterminated string constant`

แก้ด้วยการประกอบอักขระเองจาก `String.fromCharCode(92)` แทนการพิมพ์ตรง ๆ

**เป็นบทเรียนเดิมที่เคยบันทึกไว้แล้วแต่ยังพลาดซ้ำ** — งานที่ต้องเขียนอักขระพิเศษ
ลงไฟล์ผ่าน heredoc ต้องระวังทุกครั้ง หรือเลี่ยงไปเขียนไฟล์ด้วยเครื่องมือเขียนไฟล์ตรง ๆ
