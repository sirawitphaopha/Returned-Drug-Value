## 1. 🏥 ระบบ รพ.สต. ต้นทาง (ของใหญ่สุดในรอบนี้)

### รายชื่อ 13 แห่ง — พี่กันตรวจแล้วยืนยันว่าถูกต้องครบ

ค้นด้วยตัวช่วยจาก 3 แหล่งที่ตรงกัน (สปสช. · HealthServ · chonlatit)
รายละเอียดครบ — รหัส 5 หลัก · ตำบล · หมู่ที่ · ที่อยู่เว็บอ้างอิง — เก็บที่ **`docs/PCU-SITES.md`**

ชื่อในดรอปดาวน์ใช้**ชื่อสั้น**ตามที่พี่กันสั่ง:
`กู่ · กระดึ · กำแมด · หนองเชียงทูน · ตูม · นาเวียง · ดอนหลี่ · ดอนเหลือม · ตาเปียง · หว้าน · ดู่ · สวาย · ไฮ`

🚨 **ตรวจแล้วว่าไม่ซ้ำกันสักคู่** — เพิ่มแห่งใหม่ที่ชื่อชนกับของเดิมเมื่อไหร่ ต้องเติมชื่อตำบลต่อท้ายทันที

### เรื่องที่ตัดสินใจระหว่างทาง

- **เก็บเป็นชื่อ ไม่ใช่รหัส** — เป็น snapshot เหมือน `drug_name` (กฎแช่ข้อมูล)
- **รายชื่ออยู่ในฐาน ไม่ฝังในโค้ด** — เปลี่ยนชื่อไม่ต้องขึ้นเว็บใหม่
- **ไม่บังคับต้องเลือก** ใช้ป้ายแดงเตือนแทน (เหตุผลเดียวกับข้อ 3.21 ยาที่ยังไม่ใส่ราคา)
- **ย้ายออกจาก รพ.สต. ต้องล้างชื่อทิ้ง** ทั้งฝั่งจอและฝั่งเซิร์ฟเวอร์
- **ไม่ทำ UI จัดการรายชื่อในหน้าตั้งค่า** เพราะรายชื่อผู้บันทึก (`staff`) ก็ไม่มี แก้ในฐานเหมือนกัน
  จะสร้างของใหม่ที่ไม่เข้าชุดกับของเดิม → แก้ข้อความในหน้าจอให้ตรงความจริงแทน

## 2. 🐛🔴 บั๊กวันที่ — ของจริงที่เคย "แก้แล้ว" แต่ไม่เคยทำงาน

**เจอโดยบังเอิญระหว่างทดสอบเรื่องอื่น** — นาฬิกาเครื่อง 26 ส.ค. แต่ช่องวันที่ยังเป็น 25 ส.ค.
= ยาที่รับคืนวันนี้จะถูกบันทึกเป็นเมื่อวานทั้งล็อต โดยไม่มีอะไรเตือนเลย

**อาการเดียวกับข้อ 3.22 ที่ "แก้ไปแล้ว" เมื่อ 19 ส.ค.** — เพราะแก้ผิดที่

```js
if (!app.state.today || app.state.today === now) return;   // ← ตีกลับตรงนี้เสมอ
```

ตอนกู้ร่างมี `patch.today = todayISO()` อยู่แล้ว `state.today` จึงเท่ากับวันนี้เสมอ
**โค้ดที่แก้เมื่อ 19 ส.ค. เป็นโค้ดตายมาตลอด ไม่เคยได้ทำงานเลยสักครั้ง**

### วิธีแก้ + กับดักที่เกือบตกเอง

แก้ครั้งแรกเสร็จแล้วรู้ตัวว่าจะสร้างบั๊กใหม่ที่แย่กว่าเดิม —
ตัวจับเวลาเรียกทุก 60 วินาที ถ้าไม่มีอะไรกัน เภสัชกรที่**ตั้งใจ**เลือกวันย้อนหลัง
จะถูกดึงกลับเป็นวันนี้เงียบ ๆ ภายในนาทีเดียว จึงเพิ่มธง `dateTouched`

```js
const stale = !app.state.dateTouched && !!app.state.date && app.state.date < now;
if (app.state.today === now && !stale) return;
```

🚨 **`dateTouched` ห้าม persist ลง localStorage** — ต้องเป็นเท็จเสมอตอนเปิดเว็บใหม่

**ทดสอบจริง 2 รอบ**

| ทดสอบ | ผล |
|---|---|
| เปิดเว็บที่มีร่างค้างวันเก่า | ช่องวันที่เด้งเป็น 26 ส.ค. ✅ |
| เลือกวันย้อนหลัง 20 ส.ค. แล้วรอ 63 วินาที (เกินรอบตัวจับเวลา) | ยังเป็น 20 ส.ค. ไม่ถูกดึงกลับ ✅ |

**บทเรียน:** แก้บั๊กแล้วต้องพิสูจน์ด้วยพฤติกรรมจริง ไม่ใช่แค่เห็นว่าโค้ดที่เขียนดูถูกต้อง
ครั้งก่อนโค้ดถูก แต่ไม่มีใครไปถึงมัน
