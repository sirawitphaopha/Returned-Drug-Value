## 1. ย้ายราคาเข้าคลังยากลาง

**ปัญหาเดิม** — ราคาอยู่ในตาราง `mr_drug_price` ซึ่งเป็นของเว็บนี้เว็บเดียว
ME-DRP กับ TB Calculator มองไม่เห็นเลย ทั้งที่ใช้ตาราง `drugs` ร่วมกันอยู่แล้ว

**คอลัมน์ใหม่ในตาราง `drugs`**

```
unit_price          numeric(12,4)   ราคาต่อหน่วย
unit_th             text            หน่วยนับไทยเฉพาะตัวนี้
price_note          text            ที่มาของราคา
price_needs_check   boolean         รอเภสัชกรตรวจ
price_updated_at    timestamptz     แก้ล่าสุดเมื่อไร
pill_color          text            ชื่อสีเม็ดยาไทย
pill_color_hex      text            รหัสสี (เว้นว่างได้)
```

**ขั้นตอนที่ทำ (ทำแบบไม่ให้ของพังระหว่างทาง)**

1. เพิ่มคอลัมน์ก่อน — ยังไม่มีใครอ่าน ของเดิมทำงานปกติ
2. คัดลอกครบ 417 แถว
3. **ตรวจทีละแถวว่าตรงกันหมด → ไม่มีตัวไหนคลาดเคลื่อนเลยสักตัว**
4. เปลี่ยนฝั่งอ่าน (`lib/catalog.js` · `/api/drugs` · `/api/catalog`)
5. เปลี่ยนฝั่งเขียน (`/api/prices`)
6. **ไม่ลบ `mr_drug_price`** เก็บเป็นสำเนาสำรอง

### 🚨 บั๊กที่เกือบเกิด — upsert กับตารางที่มีคอลัมน์เยอะ

`/api/prices` เดิมใช้ `upsert` กับ `mr_drug_price` ซึ่งมีแค่ 6 คอลัมน์
พอย้ายมา `drugs` ที่มียี่สิบกว่าคอลัมน์ **ช่องที่ไม่ได้ส่งไปจะโดนล้างเป็น NULL ทั้งหมด**
= ชื่อยา ความแรง รูปแบบ หายเกลี้ยงทั้งตาราง

แก้เป็น `update` รายแถว ยิงทีละ 20 แถวขนานกัน
(บั๊กตระกูลเดียวกับข้อ 3.6 ใน CLAUDE.md ที่เคยเจอตอนบันทึกราคาหลายตัวพร้อมกัน)

## 2. สีเม็ดยา

พี่กันสั่งตอนแรกให้ใส่ในโค้ด แล้ว**เปลี่ยนใจเองระหว่างทาง**ว่าให้เก็บในฐาน
*"มันจะได้ไม่ต้องแก้โค้ดทุกโปรเจกต์"* — ถูกต้องกว่ามาก

```
Warfarin 2 mg   ส้ม      #d1610b
Warfarin 3 mg   น้ำเงิน   #0b62d6
Warfarin 5 mg   ชมพู     #d6337e
```

**`lib/drugPillColors.js`** — โมดูลอิสระ ไม่พึ่ง React/Next
`pillColorOf(drug)` คืน `{label, color}` · `COLOR_HEX` แปลงชื่อสีไทย 11 สีเป็นรหัสสี
ถ้าในฐานใส่แค่ชื่อสี ระบบเติมรหัสสีให้เอง

🚨 **ก๊อปไป ME-DRP แล้ว (`lib/drugPillColors.ts`) แก้ที่ไหนต้องก๊อปไปอีกที่เสมอ**

**ทำไมต้องมี** — ยาที่ผู้ผลิตแยกความแรงด้วยสีเม็ด เภสัชกรกับคนไข้จำด้วยสีมากกว่าตัวเลข
หน้าจอต้องพูดภาษาเดียวกับของจริงที่อยู่ในมือ

## 3. หน้าคลังยา

| เรื่อง | ก่อน | หลัง |
|---|---|---|
| ปุ่มล้างตัวกรอง | ไม่มี ต้องกดยกเลิกทีละอัน | มีปุ่มเดียวล้างหมด |
| ลืมสลับแป้นพิมพ์ | พิมพ์ `ทำะดน` ไม่เจออะไร | เจอ Metformin + ป้ายบอกคำที่ใช้ค้นจริง |
| แถบค้นหา | อยู่คนละบรรทัดกับตัวกรอง | แถวเดียวกัน ค้นหา 25% ตัวกรอง 75% |
| ความสูง | ช่องค้นหา 40px ชิป 34px ไม่เท่ากัน | **38px เท่ากันหมด** |
| ป๊อปแก้ไขยา | ไม่มีช่องราคา | ราคา + หน่วยนับไทย + สีเม็ดยา (มีตัวอย่างสีสด ๆ) |

🚨 **ความสูงเท่ากันต้องกำหนด `height` ตายตัว ไม่ใช่อาศัย padding**
ช่องกรอกกับ `<div>` คิดความสูงจาก padding คนละแบบ ตั้ง padding เท่ากันแล้วยังสูงไม่เท่ากัน
วิธีที่ใช้: `height:38px` + `box-sizing:border-box` + `inline-flex` + `align-items:center`
วัดจริงในโครม — ทุกช่องสูง 38 · ขอบบนอยู่ที่ 152 เท่ากันหมด
