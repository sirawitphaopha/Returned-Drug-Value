## ⚠️ กับดักของเครื่องนี้ (เจอซ้ำจากรอบเช้า)

**heredoc ใน Bash กลืน backslash** — `\b` ในซอร์ส JS กลายเป็นอักขระ backspace จริง
`\s` กลายเป็น `s` เปล่า · และ `\"` ในสตริงทำให้สคริปต์ parse ไม่ผ่าน

**วิธีเลี่ยงที่ได้ผล**
- ประกอบ backslash ด้วย `String.fromCharCode(92)`
- ใช้ `String.fromCharCode(39)` แทนอัญประกาศเดี่ยวที่ต้องซ้อนหลายชั้น
- JSX เขียน `value={''}` แทน `value=""`
- **บล็อกโค้ดยาว ๆ ให้เขียนลงไฟล์ข้อความก่อนด้วย heredoc ธรรมดา แล้วให้สคริปต์อ่านไปแทรก**
  (วิธีนี้ปลอดภัยที่สุด ใช้ตอนแก้บล็อกล็อกอินในไฟล์เทส)

🚨 **`cat > file <<EOF` ที่เนื้อหายาวเกิน ~10KB โดนตัดกลางคัน** — ต้องแบ่งเขียนทีละ ~50 บรรทัด
ด้วย `cat >>` ต่อกัน (เจอตอนเขียน `delete-who-check.mjs` รอบแรก ไฟล์ขาดครึ่ง)
