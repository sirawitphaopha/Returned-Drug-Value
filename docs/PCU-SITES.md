## ⚠️ จุดที่ยังไม่ฟันธง

### 1. ตำบลของ รพ.สต.บ้านไฮ — แหล่งขัดกัน 2 ต่อ 1

| ว่าอยู่ตำบล | แหล่งที่บอก |
|---|---|
| **พิมายเหนือ** | HealthServ · chonlatit (ระบุ หมู่ 7 ต.พิมายเหนือ) · เว็บ อบต.พิมายเหนือ ระบุ "สถานีอนามัยบ้านไฮ" เป็นสถานที่สำคัญในเขตตนเอง |
| พิมาย | ทะเบียน สปสช. รหัส 13868 |

ในตารางข้างบนใช้ **พิมายเหนือ** เพราะมี 3 แหล่งหนุน และช่องที่อยู่ของ สปสช. ดูผิดปกติ
(ขึ้นว่า "เลขที่ 13868" ซึ่งเป็นรหัสหน่วยบริการ ไม่ใช่บ้านเลขที่)

**ไม่กระทบการใช้งานเว็บ** เพราะระบบเก็บแค่ชื่อ รพ.สต. ไม่ได้เก็บตำบล
แต่ถ้าวันหน้าจะทำรายงานแยกตามตำบล ต้องถาม สสอ.ปรางค์กู่ ยืนยันก่อน

### 2. การสะกด "กระดึ" กับ "กะดึ"

สปสช. และ HealthServ เขียน **"บ้านกระดึ"** · chonlatit เขียน "บ้านกะดึ"
ใช้ **"กระดึ"** ตามทะเบียน สปสช. ซึ่งเป็นแหล่งทางการกว่า

### 3. สถานะการถ่ายโอนไป อบจ.

รพ.สต.บ้านดอนเหลือม (03389) อยู่ในชุดที่ถ่ายโอนไป อบจ.ศรีสะเกษ รอบแรก ตุลาคม 2565
รอบหลัง ๆ (2566–2567) อาจมีเพิ่ม แต่หารายชื่อรายอำเภอที่อัปเดตไม่เจอ

**ไม่กระทบเว็บนี้** — ยาที่ผู้ป่วยคืนยังเดินทางกลับมาที่ห้องยาเหมือนเดิม
เรื่องนี้กระทบแค่สายบังคับบัญชา

## รายชื่อนี้อยู่ที่ไหนในระบบ

🚨 **เก็บในฐานข้อมูล ไม่ได้ฝังในโค้ด** — แก้ได้จากหน้าตั้งค่าโดยไม่ต้องแก้โค้ดแล้วขึ้นเว็บใหม่

```
ตาราง  mr_setting  (มีแถวเดียว id = 1)
คอลัมน์ pcu_sites   jsonb  — รายชื่อที่โผล่ในดรอปดาวน์

ตาราง  mr_return
คอลัมน์ pcu_site    text   — ชื่อ รพ.สต. ของแถวนั้น (snapshot ณ วันบันทึก)
```

**ทำไมเก็บเป็นชื่อ ไม่ใช่รหัส** — ตรงกับกฎแช่ข้อมูลของโปรเจกต์นี้ (เหมือน `drug_name` และ
`recorded_by`) · ถ้า รพ.สต. เปลี่ยนชื่อวันหน้า รายการเก่าต้องยังอ่านออกว่าตอนนั้นเขียนว่าอะไร
