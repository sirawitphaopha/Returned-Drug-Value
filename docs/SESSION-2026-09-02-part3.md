### ต้นเหตุ — ระยะขอบติดลบ

ชื่อเว็บฝั่งมือถือใช้ `margin:0 -7px;padding:5px 7px`

**ระยะขอบติดลบดึงตัวถัดไปเข้ามาในระยะในของตัวเอง**
กรอบจึงยื่นไปทับตัวถัดไป **เท่ากับเลขที่ติดลบเสมอ**

```
ก่อน   ชื่อเว็บ 52–160 · วันที่ 155–280   เหลื่อม 5 จุด
หลัง   ชื่อเว็บ 52–153 · วันที่ 155–280   ห่าง 2 จุด
```

### วิธีแก้ที่ไม่ทำให้อะไรขยับเลย

```
margin:0 -7px;padding:5px 7px        →  margin:0 0 0 -7px;padding:5px 0 5px 7px
```

🚨 **ต้องถอดทั้งระยะขอบขวาและระยะในขวาพร้อมกัน** ความกว้างของกล่องรวมระยะขอบจึงเท่าเดิมเป๊ะ
**ตัวอักษรกับของทุกชิ้นหลังจากนั้นไม่ขยับเลยสักจุด** (วัดยืนยันแล้ว)

⚠️ **ถอดแค่ระยะขอบอย่างเดียวไม่ได้** จะดันช่องวันที่กับปุ่มไอคอนไปทางขวา 7 จุด

สิ่งเดียวที่หายคือแถบไฮไลต์ตอนชี้ที่เคยยื่นไปใต้ปุ่มวันที่ **ซึ่งไม่ควรมีอยู่แต่แรก**

## ② ปุ่มที่กดไม่ได้ต้องบอกเหตุผลในตัวเอง

พี่กันถาม *"มันจะออกมายังไงนะ"* → แคลร์ถ่ายภาพจริงมาให้ดู แล้วพี่กันเลือก **แบบ ก**

### สิ่งที่เห็นในภาพ

พิมพ์ `3000000000` ในป๊อปใส่จำนวนบนมือถือ

| ส่วน | เดิมทำถูกอยู่แล้ว |
|---|---|
| ข้อความแดงกลางจอ | "จำนวนสูงสุด 100,000" ✅ |
| ปุ่ม | สีเทา กดไม่ได้ ✅ |

**แต่บนปุ่มเทานั้นยังเขียนว่า**

```
เพิ่ม +1,350,000,000.00 ฿      ← Metformin เม็ดละ 0.45 × 3,000,000,000
```

🚨 **ตัวเลขหลักพันล้านสะดุดตากว่าบรรทัดเตือนสีแดงเสียอีก**
คนเห็นแวบแรกตกใจว่าระบบคิดเงินผิด ทั้งที่เป็นยอดที่ไม่มีวันบันทึกได้จริง

ปกติ        ปุ่มเขียน "เพิ่ม +13.50 ฿"    เหมือนเดิมทุกอย่าง

## 🔑 บทเรียนของรอบนี้ — พี่กันถามว่า "ออกมายังไง" ให้ถ่ายภาพ อย่าอธิบาย

### วิธีเปิดป๊อปเพื่อถ่ายภาพโดยไม่ต้องไล่กดทีละขั้น

ตั้งค่าโดยตรงผ่าน React fiber เชื่อถือได้กว่าการหาช่องกรอกแล้วกด

```js
var d = (app.state.drugs || [])[0];
app.setState({ sheet: { drug: d, kind: 'add', id: null }, sheetQty: '3000000000', sheetDisp: 'reuse' });
```

⚠️ **ช่องค้นยาฝั่งมือถือหาด้วย `placeholder` ไม่ได้** — ตัวอักษรโปร่งใสจากระบบแก้วรรณยุกต์
ข้อความที่ตาเห็นถูกวาดด้วยกล่องธรรมดาอีกชั้น (ข้อ 3.69)

🚨 **สคริปต์ชั่วคราวต้องวางใน `scripts/` ไม่ใช่โฟลเดอร์ชั่วคราวนอกโปรเจกต์**
`puppeteer-core` หาไม่เจอเพราะ node ไล่หา `node_modules` จากที่อยู่ของไฟล์ ไม่ใช่จากที่รัน
· **ลบทิ้งหลังใช้เสร็จทุกครั้ง**
