## 🧮 ระบบใหม่ 2 — ช่องจำนวนคิดเลขได้ (เฉพาะคอม)

พี่กันสั่ง: *"ใส่ 25+25 แล้วเอนเทอร์ อยากให้มันบวกให้ด้วย"* → *"พิมพ์ + - * / ได้เลย และวงเล็บได้ด้วย"*
→ *"25+25 พอกดเอนเทอร์แล้วจะกลายเป็น 25+25=50 และ 50 มีเด่น แล้วพอกดเอนเทอร์แล้วค่อยเพิ่ม"*

**ตัวคิดเลขอยู่ `components/helpers.js`** — `cleanQtyExpr` · `evalQty` · `isQtyExpr` · `splitResolved` · `exprText`

🚨🚨 **ห้ามใช้ `eval()` หรือ `new Function()` เด็ดขาด**
ทั้งสองตัวรันโค้ดอะไรก็ได้ที่อยู่ในข้อความ และ **CSP ของเว็บจริงบล็อกไว้อยู่แล้ว**
(`next.config.js` ใส่ `'unsafe-eval'` เฉพาะตอน dev — เว็บจริงจะพังเงียบ ๆ หาสาเหตุยากมาก)
วิธีที่ใช้คือไล่อ่านทีละชั้น: บวกลบ → คูณหาร → ตัวเลข/วงเล็บ

🚨 **ต้องทนกับสูตรที่ยังพิมพ์ไม่จบ** เพราะคิดใหม่ทุกตัวอักษร — `"25+"` · `"(25+25"` · `"3*("` ต้องไม่พัง

🚨 **เก็บสูตรไว้ในช่อง ต่อ `=ผลลัพธ์` ท้าย ไม่ใช่แทนที่ด้วยตัวเลขเปล่า**
`"25+25=50"` ตรวจย้อนได้ว่ามาจากการบวกอะไร · และ `evalQty` **คิดจากสูตรฝั่งซ้ายของ `=` เสมอ**
กันคนไปแก้ตัวเลขหลัง `=` เอง (ทดสอบ: `"25+25=999"` ยังคืน 50)

🚨 **ห้ามเอาไปใช้กับป๊อปอัปมือถือ** — `vals/sheet.js` ยังใช้ `cleanQty`/`qtyNum` ตัวเดิม ไม่แตะเลย

**ผลทดสอบตรรกะ**

| พิมพ์ | ได้ | พิมพ์ | ได้ |
|---|---|---|---|
| `25+25` | 50 | `25+` | 25 |
| `3*(10+2)` | 36 | `-5` | 0 |
| `1+2*3` | 7 | `999999999` | 100000 (เพดาน) |
| `(2+3)*(4+1)` | 25 | `25+25=999` | **50** (คิดจากสูตร) |

**แป้นเครื่องคิดเลข** — แป้นไม่ได้คิดเลขเอง มันแค่พิมพ์ตัวอักษรลงช่อง แล้ว `evalQty` คิดตอนกด Enter
ทำแบบนี้เพื่อให้ "พิมพ์เอง" กับ "กดแป้น" เดินทางเดียวกัน ไม่มีทางให้ผลต่างกัน

🔴 **รอบแรกลืมใส่ปุ่ม `+`** ทั้งที่ `25+25` คือโจทย์แรกสุดของพี่กัน — จัดใหม่เป็น 5 แถว

อยากให้มีปุ่มกดที่สื่อตรง ๆ"* → *"ถ้าเป็นค่าเดิม เครื่องหมายถูกจะกดไม่ได้"* → *"fix กรอบของตัวเลขด้วย"*

4. 🚨 **โครงคงที่ ปุ่ม 2 ช่องเสมอ**

```
ปกติ: [เลข 150px][✎ 26px][ที่ว่าง 26px]
แก้:  [ช่อง 150px][✓ 26px][✕ 26px]
```

ถ้าจำนวนปุ่มไม่เท่ากัน **กรอบตัวเลขเลื่อนซ้ายตอนกดแก้** — วัดจริงหลังแก้: ขอบขวา **618px** เท่ากันทั้งสองสถานะ
