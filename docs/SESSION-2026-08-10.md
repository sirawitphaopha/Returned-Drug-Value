## 2. ความเข้มข้น % ไม่เคยขึ้นเลย ทั้งที่กรอกไว้ในฐาน

## 5. 🚨 ยาสูตรผสม — ครอบวงเล็บให้ความแรง

ความต่างที่พี่กันชี้จากภาพเทียบ 2 เว็บ

```
❌ Ampicillin + Sulbactam 2 + 1 g       ← มีเครื่องหมาย + สองที่ แยกไม่ออก
✅ Ampicillin + Sulbactam (2 + 1 g)
```

ME-DRP ทำแบบนี้มาตลอด — [`lib/helpers.ts` → `drugFlatLine`](../../ME-DRP-fresh/lib/helpers.ts)
เหตุผลอยู่ในคอมเมนต์ของเขาเอง: *"ไม่สับสนกับ + ของชื่อยา"*

**ความแรงเป็นข้อมูลความปลอดภัย** อ่านผิดตัวไม่ได้ · ในฐานมียาผสม **49 ตัว**

### กับดักที่ต้องระวังตอนแก้

`splitDrugName()` ใน `helpers.js` แยกชื่อ/ความแรงด้วย regex ที่บังคับว่า
**ความแรงต้องขึ้นต้นด้วยตัวเลข** พอความแรงถูกครอบวงเล็บก็แยกไม่ออกทันที

แก้ regex ให้รับวงเล็บด้วย แต่ **ในวงเล็บต้องขึ้นต้นด้วยตัวเลขเท่านั้น**

```js
/^(.*?)\s(\(\d[^)]*\)|\d[\d\w./+\-% ]*)$/
```

ถ้าไม่บังคับข้อนี้ ยาชื่อซ้ำที่ระบบต่อท้ายด้วย `(vial)` `(injection)`
จะถูกจับวงเล็บนั้นมาเป็น "ความแรง" แทน

**เทสด้วยการรันโค้ดจริง** (`node` เรียก `buildDrugNames` + `splitDrugName` ตรง ๆ ไม่ผ่านเบราว์เซอร์)
8 เคส — ยาผสม 3 · ยาเดี่ยว 2 · ยามี % 1 · ยาชื่อซ้ำ 2

**เช็คก่อนแก้ว่ากระทบข้อมูลเก่าไหม:** `select ... from mr_return where drug_name like '%+%'` → **0 แถว**
(ถ้ามีแถวเก่าอยู่ ชื่อใน snapshot จะไม่ตรงกับชื่อใหม่ แล้ว Top 10 หน้าสรุปจะแยกเป็นสองก้อน)

ไม่เอา Preg B/Renal (เว็บยาคืนไม่ได้สั่งจ่ายยา ใส่ไปจะรก) และไม่ขยายฟอนต์

วางไว้**นำหน้าหน่วยนับ**ในบรรทัดล่าง ตำแหน่งเดียวกับ ME-DRP → `IV · ขวด`
สีเข้มกว่าหน่วยนับนิดหนึ่ง เพราะเป็นข้อมูลของตัวยา ส่วนหน่วยนับเป็นเรื่องการนับ

ค่าที่มีในฐาน 11 แบบ: `IV · IM · SC · oral · topical · ophthalmic · nasal · rectal · inhaled · MDI · transdermal`
(อีก 8 ตัวยังไม่กรอก ตัวนั้นจะไม่วาดอะไรเลย)

ใส่ทั้ง **ผลค้นหาหน้าบันทึก** และ **หน้าตั้งราคายา** ให้ตรงกัน

## 🔓 รอบเสริม — ปลดล็อกเว็บเฉพาะตอนรันในเครื่อง

พี่กันเสนอจะเอารหัสผ่านไปใส่ใน env ให้แคลร์เข้าเว็บได้เอง

**ตอบพี่กันว่าไม่ได้** — แคลร์กรอกรหัสผ่านลงช่องในเว็บไม่ได้ ไม่ว่ารหัสจะวางอยู่ที่ไหน
เป็นข้อห้ามที่ติดตัวมา เอารหัสไปใส่ก็ไม่ช่วยอะไร

**ทางที่เลือกแทน:** ปลดล็อกเฉพาะเว็บที่รันในเครื่อง เพราะมีแค่คนหน้าจอเครื่องนั้นที่เข้าถึงได้อยู่แล้ว
การบังคับกรอกรหัสจึงไม่ได้เพิ่มความปลอดภัย มีแต่ทำให้เทสไม่ได้

```js
// lib/auth.js
function devOpen() {
  if (process.env.NODE_ENV !== 'development') return false;   // ← ชั้นที่ 1
  return (process.env.MRV_DEV_OPEN || '').trim() === '1';     // ← ชั้นที่ 2
}
export function authEnabled() {
  if (devOpen()) return false;
  return !!(process.env.MRV_PASSWORD || '').trim();
}
```

**ต้องผ่านสองชั้นพร้อมกัน** — Cloudflare build เป็น production เสมอ
ต่อให้ใครเผลอไปตั้ง `MRV_DEV_OPEN` บน Cloudflare ก็ไม่มีผล เพราะชั้นแรกไม่ผ่าน
และ `.env.local` อยู่ใน `.gitignore` (ตรวจด้วย `git check-ignore -v .env.local` แล้ว)

**ผลที่ได้ทันที** — เทสหน้าจริงเองได้ครั้งแรกในรอบนี้ เห็นกับตาว่า:

```
Ampicillin + Sulbactam (2 + 1 g) vial      Dexamethasone 4 mg/mL injection
IV · ขวด                                     IV · หลอด
```

ปิดข้อค้างจากรอบก่อนที่เขียนไว้ว่า "ยังไม่ได้เห็น injection กับ IV กับตา"

### 🐛 เจอระหว่างทาง — dev server ค้างแบบไม่ตาย

พี่กันแจ้งว่าเปิด localhost ไม่ติด ตรวจแล้วพบว่า **พอร์ตยัง LISTENING อยู่แต่ไม่ตอบเลย**

## 1. ปุ่มทุกปุ่มกดด้วยคีย์บอร์ดได้ (107 จุด)

ปัญหา: ปุ่มทั้งเว็บเป็น `<div onClick>` ตามมอคอัป → Tab ไม่ถึง Enter ไม่ทำงาน
หน้าบันทึกกด Tab ได้ **4 ชิ้น** ทั้งที่กดด้วยเมาส์ได้ 15 ชิ้น

**ทางที่ไม่เลือก:** ไล่ใส่ `tabIndex` ทีละจุด — 107 จุด ตกหล่นแน่ และไฟล์อ่านยากขึ้นทุกบรรทัด

**ทางที่ไม่เลือก 2:** สแกน DOM หลังวาดจอแล้วเติม attribute — React ไม่ได้ใส่ `onclick` จริงบน DOM
(ใช้ event delegation ที่ root) จึงหาไม่เจอ และต้องเรียก `getComputedStyle` ทุก element = ช้ามาก

**ทางที่เลือก:** ตัวช่วยกลาง `kb()` ใน `helpers.js` แล้วแปลงด้วย `sed` ทีเดียว
คืน `{onClick, role:'button', tabIndex:0, onKeyDown}` ครบในตัว

แปลงอัตโนมัติ **103 จาก 107 จุด** · อีก 4 จุดเป็นเงื่อนไขสามทาง (`onClick={a ? b : undefined}`) แก้มือ

**ผล:** หน้าบันทึกแบบคอม Tab ถึง **29 จุด** (ปุ่ม 25 + ช่องกรอก 4)

⚠️ ต้องเติม `import { kb }` ให้ทุกไฟล์ที่ sed แตะ ไม่งั้นขึ้น `kb is not defined` ตอนรัน

## ✨ ความสามารถใหม่ 5 อย่าง

พี่กันให้แคลร์เสนอว่าระบบค้นหายังมีจุดด้อยอะไร แล้วเคาะทีละข้อ

### 1. พิมพ์หลายคำ

```
"amox clav"  →  Amoxicillin + Clavulanic acid
"clav amox"  →  เจอเหมือนกัน (สลับลำดับได้)
```

แยกคำค้นเป็นชิ้น ๆ แล้วเช็คว่าทุกชิ้นอยู่ในชื่อยา/ชื่อการค้า/ตัวย่อไหม
Google · PubMed · Algolia ค้นแบบนี้กันหมด

### 2. 🆕 ลืมสลับแป้นพิมพ์ (พี่กันชอบมากที่สุด)

> *"เฮ้ยยยยย อันนี้ทำได้เหรอออ เพราะเราแม่งลืมเปลี่ยนภาษาตลอดดด"*

```
พิมพ์ "ทำะดนพทรื"  →  แปลงเป็น "metformin"  →  เจอ Metformin
```

ตารางแป้นเกษมณี (Kedmanee) แปลงไทยเป็นอังกฤษ · ค้นด้วยคำเดิมไม่เจอก่อนค่อยแปลง

⚠️ **คนละเรื่องกับ "ตัวแปลงอักษรต่างด้าว" ของ HCV** (พี่กันทักถูก)
อันนั้นแก้ตัวอักษรเพี้ยนจากการก๊อป (encoding พัง) · อันนี้แป้นพิมพ์คนละภาษา

**พี่กันขอเพิ่ม 2 อย่างหลังเห็นของจริง**
- ป้าย `ค้นว่า metfo` ข้างปุ่ม ✕ — บอกว่าระบบเข้าใจว่ากำลังหาคำว่าอะไร
- **ไฮไลต์ในชื่อยาด้วยคำที่แปลแล้ว** — เดิมเจอยาแต่ไม่ไฮไลต์อะไรเลย
  เพราะ `ทำะดน` ไม่มีอยู่ในคำว่า Metformin สักตัว

จึงเพิ่ม `searchDrugsEx()` ที่คืน `{ list, used, swapped }` แทนที่จะคืนแค่ผลลัพธ์

### 3. ยาที่คืนบ่อยลอยขึ้นก่อน

สร้าง `mr_hot_drug_ids()` ในฐานข้อมูล ส่งมาตอน `/api/bootstrap`
**เป็นตัวตัดสินอันดับที่ 3 เท่านั้น — ยังแพ้ "เจอที่ต้นชื่อ" เสมอ**

⚠️ โหมดตัวอย่างต้องคำนวณเองจาก `box.rows` ไม่งั้นเทสไม่เห็นผล

### 4. ค้นด้วยตัวย่อ

เพิ่มช่อง **`drugs.abbrev`** ใส่ตัวย่อ **127 ตัว**

```
cpm  → Chlorpheniramine (CPM)
hctz → Hydrochlorothiazide (HCTZ)
inh  → Isoniazid (INH)
mst  → Morphine sulfate (MST) ทุกรูปแบบ
```

ถ่วงอันดับไว้ที่ 500+ — มาหลังชื่อสามัญ (0+) แต่มาก่อนชื่อการค้า (900+)

**แสดงในวงเล็บสีม่วง `#6d3b9e`** (พี่กันเลือกสีเอง เพื่อแยกจากชื่อการค้าที่เป็นสีเทล)

🚨 **ถ้าตัวย่อมีอยู่ในชื่อยาแล้วต้องไม่วาดซ้ำ** ไม่งั้นได้ `Hydrochlorothiazide (HCTZ)(HCTZ)`

**ลบตัวย่อออกจากชื่อยาแล้ว 8 แถว** (พี่กันสั่งตอนท้าย)
```
Hydrochlorothiazide (HCTZ)                    → Hydrochlorothiazide
Depot Medroxyprogesterone acetate (DMPA)      → Depot Medroxyprogesterone acetate
Morphine sulfate (MST) × 2                    → Morphine sulfate
Insulin regular (RI) · Isophane insulin (NPH) → ตัดวงเล็บออก
Isophane insulin (NPH) + Insulin regular (RI) → ตัวย่อเป็น "NPH RI" ทั้งคู่
```

ผลข้างเคียงที่ดี: เมื่อก่อนมีแค่ Morphine 2 ตัวที่ชื่อมี (MST)
ตอนนี้ Morphine ทุกรูปแบบ (syrup · injection · tab) ค้นด้วย `mst` เจอหมด

**ตัวย่อที่ตกลงว่าไม่ใส่**
- Paracetamol — พิมพ์ `para` ก็เจอ และคนไม่ย่อกัน (พี่กันบอก)
- Bactrim · Lasix · Ventolin — เป็นชื่อการค้า ต้องอยู่ช่อง `brand` (พี่กันบอก)
- Co-trimoxazole — เป็นชื่อสามัญทั้งคู่ ไม่ใช่ตัวย่อ (พี่กันบอก)
- Vitamin B12 · C · D3 · K1 — เป็นชื่อที่คนเรียกเป็นหลัก เก็บไว้ในชื่อยา

## 🚨 เรื่องที่เจอระหว่างทาง — สำคัญกว่าที่กำลังทำ

### 1. ER / IR / SR มีในฐานแต่ไม่เคยแสดงเลย

พี่กันถาม *"เราเห็นใน MST มันคือ ER นี่นา แล้วคำนี้หายไปไหน"*

ตรวจแล้ว — `drugs.release` มีข้อมูลอยู่ **12 ตัว** แต่ไม่มีโค้ดตรงไหนหยิบมาใช้เลย
(แบบเดียวกับ % และชื่อการค้าที่เพิ่งแก้ไปรอบก่อน)

**อันตรายที่สุดในบรรดาช่องที่หายไป**
```
Morphine sulfate 10 mg ER  = ออกฤทธิ์ 12 ชั่วโมง · กิน 2 ครั้ง/วัน
Morphine sulfate 10 mg     = ออกฤทธิ์ 4 ชั่วโมง  · กิน 6 ครั้ง/วัน
```

**และในคลังมีคู่ที่ต่างกันแค่นี้จริง ๆ**
```
Sodium valproate 200 mg  release = ER
Sodium valproate 200 mg  release = IR   ← เดิมแสดงเหมือนกันทุกตัวอักษร
```

🚨 **ใส่ลงใน "ชื่อยา" ไม่ใช่แค่ป้ายบนจอ** เพราะชื่อถูกแช่ลง `mr_return` ตอนบันทึก
ถ้าเก็บแค่ชื่อธรรมดา เปิดประวัติย้อนหลังจะไม่รู้ว่าตัวไหนเป็น ER

พี่กันเลือกรูปแบบเอง: **เอียง + ตัวหนา + วงเล็บ + แดงอมชมพู `#b02a5b`**
(เลือกจากมอคอัป 4 แบบที่แคลร์วาดให้ดู)

### 2. 🔴 หน้าสรุปจับกลุ่มด้วย "ชื่อยา" ไม่ใช่ "รหัสยา"

พี่กันถาม *"แม้จะเปลี่ยนชื่อยาแล้ว ระบบจะยังมองว่าเป็นตัวเดียวกันใช่มะ"*

ตรวจแล้ว — **ME-DRP ทำแล้ว แต่เว็บนี้ยังไม่ได้ทำ** (`mr_summary` เขียน `group by drug_name`)

```
Morphine sulfate (MST) 10 mg   คืน 5 ครั้ง   ← ชื่อเก่า
Morphine sulfate 10 mg ER      คืน 3 ครั้ง   ← ชื่อใหม่ ยาตัวเดียวกัน
                                              Top 10 เห็นเป็น 2 ตัวแยกกัน
```

**รอบนี้แคลร์เพิ่งเติม ER เข้าชื่อยา 12 ตัว + ลบตัวย่อออกจากชื่อ 8 แถว**
ถ้าไม่แก้เรื่องนี้ก่อน ยาพวกนี้จะนับแยกทันทีที่มีข้อมูลจริง

แก้ใน `scripts/008_group_by_drug_id.sql` — ใช้กติกาเดียวกับ ME-DRP
```sql
case when r.drug_id is null then 'txt:' || r.drug_name
     else 'id:' || r.drug_id::text end as gkey
```
มีรหัสใช้รหัส · ไม่มีรหัสใช้ชื่อ · **ป้ายที่โชว์ใช้ชื่อล่าสุดจากคลังเสมอ**

⚠️ ทันเวลาพอดี — `mr_return` ยังไม่มีข้อมูลจริงสักแถว
ถ้ารอจนใช้งานแล้วค่อยแก้ ตัวเลขที่รายงานผู้บริหารไปจะขยับย้อนหลัง
