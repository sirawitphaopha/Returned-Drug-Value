## การตัดสินใจสำคัญ 5 ข้อ พร้อมเหตุผล

**1. ทำตารางราคาแยก ไม่แก้ `drugs`**
`public.drugs` 417 แถว ใช้ร่วมกับ TB Calculator และ ME-DRP ที่รันจริงอยู่ แตะแล้วพังทั้งสามที่
ราคาและหน่วยนับของแอปนี้เลยไปอยู่ในตารางใหม่ `mr_drug_price` ที่ผูกด้วย `drug_id`

**2. แช่ราคาไว้ในแถว (`mr_return.unit_price`)**
นี่คือหัวใจของแอป ถ้าราคายาเปลี่ยนกลางปี ตัวเลข KPI ย้อนหลังต้องไม่ขยับ
เหมือนใบเสร็จที่ออกไปแล้ว ต่อให้ขึ้นราคาทีหลัง ยอดในใบเสร็จเก่าก็ไม่เปลี่ยน
ผลตามมา: `PATCH` ห้ามแตะ `unit_price` เด็ดขาด แก้ได้แค่จำนวนกับสถานะ

**3. `mr_return.drug_id` ไม่ผูก FK**
แถวมี snapshot ครบอยู่แล้ว ไม่ต้อง join · FK จะไปขวางการแก้ตาราง `drugs` ของเว็บอื่น
ตรงกับที่ ME-DRP ทำไว้อยู่แล้ว (`incidents.drug_ids` ก็ไม่มี FK)

**4. ไม่มี API ค้นหายา**
โหลดยาทั้ง 417 ตัวทีเดียวตอนเปิดเว็บ (~7 KB) แล้วค้นในเครื่อง
เพราะมอคอัปค้นแบบทันที ไม่มีดีเลย์ ไม่มีสถานะกำลังโหลด
ถ้าเปลี่ยนไปยิงเซิร์ฟเวอร์ทุกตัวอักษรจะรู้สึกช้าลง และเน็ตโรงพยาบาลไม่ไหว

**5. ใส่ตัวแปลง CSS หนึ่งตัว แทนการแปลงสไตล์ด้วยมือ**
มอคอัปมีสไตล์ฝังในแท็กราว 600 จุด ถ้าแปลงเป็น object ทีละจุดจะเพี้ยนแน่นอน
ใส่ `s('display:flex;gap:7px')` แล้วก๊อปข้อความ CSS มาทั้งดุ้น
ได้ 3 อย่าง: เทียบกับต้นฉบับได้ตรง ๆ · เรื่องฟอนต์แก้ที่เดียว · **ไม่มีรหัสสีไหนถูกแตะเลย**

## งานที่เหลือ / ต้องคุยต่อ

1. **ใส่ราคายาจริง** — ตอนนี้ทุกตัวเป็น 0 ตัวเลข KPI จะยังไม่มีความหมายจนกว่าจะใส่ราคา · รอไฟล์ราคาจาก HIS
2. **เลือกยาที่คืนบ่อย 6 ตัว** — ตอนนี้ว่าง ให้พี่กันเลือกเองในหน้าตั้งค่า
3. **heparin กับ TA** — ตั้งเป็นขวดทั้ง 2 ขนาดไปก่อน ถ้าตัวไหนควรเป็นหลอดแก้ได้ในหน้าจัดการราคา
4. **ปุ่ม "ออกจากระบบ" ในหน้าตั้งค่า** — ยังไม่มีระบบเข้าสู่ระบบ จะเอาออกหรือเก็บไว้
5. **ช่องคนบันทึก** — ไม่มีระบบเข้าสู่ระบบแปลว่าไม่รู้ว่าใครกรอก ถ้าอนาคตอยากรู้ ควรเพิ่มตั้งแต่ตอนนี้ (เพิ่มทีหลังต้องย้ายข้อมูล)
6. **โดเมน** — ใช้ซับโดเมนของ `sirawitphaopha.life` เหมือน wordbank หรือขึ้น `.workers.dev` ไปก่อน
7. **ขึ้น Cloudflare Workers** — ต้องตั้ง env vars บน Cloudflare ก่อน
