## 🔑 เรื่องที่ใหญ่ที่สุด — ชื่อยาดึงจากคลังเสมอ

**พี่กันจับได้เอง:** หน้าประวัติมี Warfarin 5 mg สองชื่อ ทั้งที่เป็นยาตัวเดียวกัน

```
บันทึก 08:37 น. → "Warfarin 5 mg"
บันทึก 12:21 น. → "Warfarin 5 mg (tab)"
```

เพราะระหว่างนั้นสูตรชื่อถูกแก้ · พี่กันทัก **"เราอยากให้ชื่อเดียวมันลิงก์ไปทุกอย่างในเว็บ
แม้ชื่อจะเปลี่ยนไปก็ตาม เรามีระบบ id อยู่นี่นา"**

**แก้:** ทุกหน้าประกอบชื่อจากคลังใหม่ทุกครั้ง — `mr_drug_label(d drugs, fallback)` ฟังก์ชันกลาง
รับทั้งแถวจากคลัง เพิ่มคอลัมน์ใหม่แล้วแก้ที่เดียว (`scripts/011_drug_label_from_catalog.sql`)

| | ก่อน | หลัง |
|---|---|---|
| ประวัติ · แก้ไขล็อต · ใบสรุป | ชื่อที่แช่ไว้ | ชื่อจากคลัง |
| สรุป Top 10 | ชื่อจากคลัง ไม่มีรูปแบบยา | ครบ |

🚨 **`drug_name` ยังเก็บครบทุกแถว** ส่งมาคู่กันในชื่อ `savedName` — เป็นหลักฐานตอบผู้ตรวจ
🚨 **ราคาที่แช่ไว้ไม่ถูกแตะเลย** ยอดรวม 6,041.50 เท่าเดิมตลอดการแก้
🚨 ค้นได้ทั้งชื่อเก่าและชื่อใหม่

## 🎨 ชื่อยาเต็มยศพร้อมสี — บทเรียนที่เสียเวลาที่สุดของวัน

พี่กันสั่ง *"ชื่อจัดเต็ม มียี่ห้อด้วยนะ"* แล้วตามด้วย **"ไหนสี"** ถามซ้ำ 3 รอบ

### 🔴 พลาด: ใส่ชื่อเต็มลงในตัวชื่อ แล้วหน้าจอวาดซ้ำ

```
Morphine sulfate 10 mg/mL injection injection      ← ซ้ำ
Morphine sulfate 20 mg cap (ER) (Kapanol) cap (Kapanol)
```

**ต้นเหตุ:** `nameParts` เดาชิ้นส่วนชื่อจากการอ่านข้อความ พอสูตรชื่อเปลี่ยนก็เดาผิดทันที
และ `(IR)` หายไปเพราะไม่อยู่ในตำแหน่งที่ตัวเดาคาดไว้

**แก้ถูกทาง:** เลิกเดา ให้เซิร์ฟเวอร์ส่ง**ข้อมูลดิบรายช่อง**มา แล้ววาดทีละส่วน
(`generic` `strength` `strengthUnit` `percent` `release` `form` `brand` `abbrev` `pillColor`)

### สิ่งที่ได้

- **`components/pages/drugname.jsx`** ตัววาดชื่อยากลางตัวเดียวของทั้งเว็บ
  ใช้ที่ผลค้นหา · ตารางรายการ · ประวัติ · สรุป · แก้ไขล็อต
- ลำดับ: ชื่อสามัญ (ตัวย่อ) (สีเม็ด) ความแรง (%) รูปแบบยา (ER/IR) (ยี่ห้อ)
- 🚨 **รูปแบบยาไม่ใส่วงเล็บ ที่เหลือใส่** ตามภาพที่พี่กันชี้ให้ดู
- 🚨 **`lib/drugName.js` คืนแค่ชื่อพื้นฐาน** รูปแบบยา/ER/ยี่ห้อ/สี ไม่อยู่ในนั้น
  เพราะหน้าจอวาดเองพร้อมทาสี ใส่ด้วยจะซ้ำสองรอบ
- **เลขความแรงเป็นสีเม็ดยาจริง** — Warfarin 2 ส้ม · 3 น้ำเงิน · 5 ชมพู (วัดค่าสีจริงยืนยันแล้ว)
